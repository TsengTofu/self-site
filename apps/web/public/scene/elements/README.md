# 觸發點圖層素材規格

把手繪的去背替換圖存成 `<itemId>.png` 放進這個資料夾,網站就會自動貼到對應觸發點的位置上;
沒放檔案的物件會維持底圖(`room-empty.jpg`)上原本烘焙好的樣子,不影響畫面。

`cat.png` / `girl.png` 是躲貓貓彩蛋與「有人版」場景的素材,跟這套插槽系統無關,不用管它們。

## 通用規格

- **透明背景 PNG**。
- **畫布比例 = 對應 rect 的比例**:渲染時用 `preserveAspectRatio="none"` 滿版貼合插槽,
  比例不對的圖會被拉伸變形。
- 圖面要**完整蓋住**底圖上該物件烘焙的輪廓,不然會看到兩層疊影。
- 建議輸出 **2×** 尺寸(例如 headphones 用 480×330),縮放顯示時比較銳利。
- 底圖尺寸 **2752 × 1536**,下表 rect 的 x / y / w / h 都是原圖像素座標(與
  `src/components/scene/hotspots.ts` 同一套系統)。

## 插槽表

| itemId | rect (x, y, w, h) | 建議輸出尺寸(2×) |
|--------|-------------------|-------------------|
| `phone` | 1258, 998, 110, 70 | 220 × 140 |
| `laptop` | 1300, 750, 290, 250 | 580 × 500 |
| `headphones` | 2052, 1232, 240, 165 | 480 × 330 |
| `musicPlayer` | 1545, 690, 205, 125 | 410 × 250 |
| `backpack` | 555, 390, 200, 385 | 400 × 770 |
| `notebook` | 1090, 992, 185, 85 | 370 × 170 |
| `skateboard` | 1908, 748, 160, 497 | 320 × 994(多邊形熱區的外接框) |

## 調整入口

插槽的座標與清單定義在 `src/components/scene/element-layers.tsx` 的 `ELEMENT_SLOTS`,
改那裡就能新增插槽或微調位置。

## 長期選項

等物件都畫完之後,可以把 `room-empty.jpg` 換成一張「清空版」底圖(桌面淨空,沒有這些烘焙物件),
讓這裡的元素圖成為畫面上唯一的來源。
