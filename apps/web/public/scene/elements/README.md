# 場景元素圖層素材規格

底圖(`room-empty.jpg`)是**清空的房間**,畫面上所有家具與物件都是一張張去背元素圖
逐層貼出來的(使用者提供)。**PNG 源檔放 `apps/web/assets/scene/elements/`**(不進 public,
不跟著 deploy 出去),這個資料夾放的是網站實際讀的同名 `.webp`。
要換某個物件:覆蓋 assets/ 裡的 PNG → 跑一次轉檔腳本(見文末)。

`cat-<pose>.png`(sleep/back/stretch/walk)是「找貓咪」彩蛋的素材,由 cat-peekaboo.tsx 管理(姿勢×位置表在該檔 SPOTS),渲染在打光層之下、人物摸貓狀態時不出現。

## 通用規格

- **透明背景 PNG**。
- **畫布比例 = 對應 rect 的比例**:渲染時用 `preserveAspectRatio="none"` 滿版貼合,
  比例不對的圖會被拉伸變形(裁掉多餘透明邊之後再對照下表)。
- 建議輸出 **2×** 尺寸,縮放顯示時比較銳利。
- 底圖尺寸 **1920 × 1080**,下表 rect 的 x / y / w / h 都是原圖像素座標
  (與 `src/components/scene/hotspots.ts` 同一套系統)。
- 疊放順序(誰蓋住誰)在 `element-layers.tsx` 的 `LAYERS`:
  背包 → 矮櫃 → 盆栽 → 音響 → 筆電 → 檯燈 → 手機 → 長板 → **床 → 耳機 → 椅子(最前)**。

## 什麼時候看得到新圖

`src/app/page.tsx`(server component)用 `fs.readdirSync` 讀這個資料夾,決定哪些圖層要渲染:

- **`pnpm dev`**:重新整理頁面就會讀到新放的圖。
- **`pnpm build`**:清單是 build 期就決定好的,加了新圖要重新 build 才會生效。

## 窗外海景(四時段)

`window-dawn/day/sunset/night.png`:由使用者的四張海景圖經**透視變形**對齊玻璃四角
(貼圖框 659, 203, 470, 410;變形參數見專案外 scratchpad 腳本,重做時用像素偵測玻璃
四角 + 取樣內縮 + 梯形遮罩)。四張全掛載、跟著時段淡變;渲染在所有元素之下。

## 時段打光層

`public/scene/light-<phase>.png`(不在 elements/):帶 alpha 的整張漸層,壓在場景
最上層(熱區/貓之下),四張全掛載淡變。強度調整入口:photo-scene.tsx `LIGHT_INTENSITY`。

## 找貓咪彩蛋(cat-<pose>.png)

三花貓每次載入隨機一種姿勢出現在一個角落,點到累計(localStorage self-site:cat-finds);
`?catspot=N` 固定校準。人物 `girl-cat` 狀態出現時貓不單獨出現(同一隻)。

藏點由使用者指定;「躲在盆栽後面」是把 plant.png 以同一個 DECOR rect **再疊繪一次**
在貓上面,接著把**當前人物狀態也疊繪一次**(同 GIRL_RECTS、同步淡變),
形成 貓 < 盆栽 < 人 的正確前後關係(使用者指定:盆栽後的貓圖層要在人類後面)。
躲盆栽的兩點都調過位:**頭(與前爪)要完全藏在花盆後面**,只露背/屁股/尾巴。
注意:桌機版底圖 cover 裁切,太靠左右邊緣的點在窄視窗可能被裁掉。

非出血圖層(貓/人物)與畫面邊界保留 ≥20px;唯一例外是 N7(刻意走出畫面)。

## WebP 轉檔(前端讀的是 .webp)

PNG 源檔在 `apps/web/assets/scene/elements/`,前端(element-layers.tsx 的 elementSrc)讀本資料夾的同名 .webp。
**新增或覆蓋 PNG 後執行:`python3 apps/web/scripts/convert-elements.py`**(冪等,只轉比 .webp 新的;`--force` 全部重轉)。
page.tsx 的可用清單看的是本資料夾的 .webp 檔名,轉檔沒跑圖層就不會出現。
